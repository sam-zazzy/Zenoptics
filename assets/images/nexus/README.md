# Nexus page images

The Nexus page (`nexus/index.html`) expects these files in this folder.
Until a file is here, the page shows a grey box with the image description.
To add an image, save it here with the exact file name below. No code change is needed.

| File | Where on the page | What it should show |
|---|---|---|
| `nexus-1-ai-answer.webp` | Hero, top of the page | An AI answer in Nexus with the KPI definition and source reports behind it |
| `nexus-2-curation-studio.webp` | "Review business context in the Semantic Curation Studio" | Semantic Curation Studio, with the Curation Health Index visible |
| `nexus-3-business-terms.webp` | "Map everyday language to business definitions" | The screen where teams curate business terms and aliases. Do not show a studio name, preview panel or bulk upload until Product confirms them |
| `nexus-4-knowledge-graph.webp` | "See how your reports, KPIs, and business concepts connect" | Knowledge Graph view with reports, KPIs, and business concepts as linked nodes |
| `nexus-5-question-context.webp` | "See the context behind an AI analytics question" | A verified demo of a net sales variance question, showing the KPI definition and source reports where the interface shows them |

Screenshot size: 1600 x 1000 px (16:10), WebP format.
The page crops each screenshot to 16:10 from the top, so keep the important part of the screen away from the bottom edge.
Do not show internal labels in a screenshot, such as "ZIVA" or "Query Plan". Do not show a confidence score or a declined answer until Product confirms that behavior.
